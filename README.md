# 🎵 Moodify

Moodify is a mood-based music playlist generator built with HTML, CSS, and JavaScript — no backend or APIs required! Users can select a mood, describe their feelings, or even get a surprise playlist.


### 🎭 Mood Selection Page


## 🚀 Features

- 🎭 **Mood Selection** — Choose from predefined moods (happy, sad, relaxed, etc.).
- ✍️ **Describe Your Mood** — Type in how you feel and let Moodify guess your mood.
- 🎁 **Surprise Me** — Get a randomized playlist for a spontaneous experience.
- 🧠 **Mood History** — View and revisit previously selected moods.
- 🔍 **Search & Filters** — Filter playlists by genre, tempo, and era.
- 🎧 **Custom Audio Player** — Track title, artist, album, and real-time duration display.
